# Plant Care Tracker (Client)

**Live:** https://plant-care-tracker-app-73090.web.app/

## Overview
A responsive Plant Care Tracker web app built with React and Tailwind. Users can sign up, add plants, set watering reminders, and view their plant list. Designed mobile-first and integrates with a backend API (Express + MongoDB) or Firebase.



## Main Technologies
- React (Vite)
- Tailwind CSS + DaisyUI
- React Router
- Firebase Authentication (or JWT)
- Axios

## Core Features
- User signup / login (Firebase Auth or JWT)
- Add / edit / delete plants (CRUD)
- Plant details page with care notes
- Schedule reminders (date/time stored in backend)
- Responsive UI for mobile & desktop

## Dependencies
- react, react-dom
- react-router-dom
- axios
- firebase (if using)
- tailwindcss, postcss, autoprefixer
- react-hook-form
